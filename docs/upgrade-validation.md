## 真实模型试运行建议

配置自己的模型后，用一个不含敏感资料的小型副本仓库，完成以下流程：

1. 读取 README，定位一个函数并核对行号。
2. 第二轮询问上一轮结论，验证连续性。
3. 请求一个小修改，先拒绝审批，检查文件 hash 未变化。
4. 再次明确要求修改并批准，检查实际 diff。
5. 退出后使用同一个 --session，询问已完成的修改。

记录模型 ID、参数、提示、实际文件变化、任务是否完成、耗时和 token；重复运行后再计算任务成功率。不要将工程测试通过数当成真实模型表现。
